# Devlog

## v0.2: rebuild as a measured system

v0.1 (commits up to `a89c5ce`) was a working LangGraph demo over an 8 KB fictional policy file. Its README made claims
that the code could not support. They were removed rather than carried over:

| v0.1 claim | Why it was withdrawn |
|---|---|
| RAGAS faithfulness 0.886, answer relevancy 0.699, context precision 0.087, context recall 0.920 | `evaluation/run_eval.py` called `ragas.evaluate` without a judge LLM, which defaults to OpenAI; the judge, RAGAS version and logs were not recorded, so the numbers cannot be reproduced. With 5 chunks of ~530 characters retrieved from an 8 KB corpus, every query saw about a third of the knowledge base, so recall near 0.9 says little about the retriever. The README's "token-ratio effect" explanation of 0.087 context precision was wrong: RAGAS context precision is an LLM-judged, rank-weighted relevance score. |
| "−49 % retrieval failures", "+15–30 % recall", "+11.2 % accuracy" | Figures from the Contextual Retrieval blog post and other papers, not measurements on this project. Paper numbers now appear only in "Paper (authors, year)" columns. |
| "14 prompt injection patterns", "live catches" | There were 12 patterns and no measurement. On public attack sets the original patterns detect 23.0 % of attacks (`results/guardrails/injection.json`, row `regex_v0`). |
| "5 fully executed notebooks" | 4 notebooks existed; notebook 04 contained a "simulated results" branch with invented scores. Notebooks were removed; figures are generated by `scripts/make_figures.py` from `results/`. |
| "production-grade" | No tests, CI, API, or container. The word is no longer used. |

Other v0.1 behaviours fixed in v0.2:
- the input guard blocked any 9-digit number as an SSN / routing number;
- regulation questions mentioning crypto were rejected as off-topic;
- the output guard's grounding check never ran (no context was passed to it);
- the action guard's sanitised arguments were never used;
- the router only changed the system prompt;
- an assistant-generated notes file and local audit logs were committed.
